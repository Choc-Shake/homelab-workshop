# 05 Resources

Stuff worth looking at after the workshop. If you only pick one from each section, pick the first.

## Learning Docker

- [Docker's Get Started guide](https://docs.docker.com/get-started/). Free, hands-on, and gets into building your own images with a Dockerfile.
- [Compose file reference](https://docs.docker.com/reference/compose-file/). Every option you can put in a `compose.yaml`.
- [Docker Curriculum](https://docker-curriculum.com/). An older but solid beginner tutorial where you build and deploy a small app.
- [roadmap.sh Docker](https://roadmap.sh/docker) and [DevOps](https://roadmap.sh/devops) roadmaps, if you're aiming for DevOps or cloud co-ops and want to know what to learn next.

## Finding apps

- [awesome-selfhosted](https://awesome-selfhosted.net). The big categorised list of free self-hostable software.
- [selfh.st](https://selfh.st). A weekly self-hosting newsletter plus an app directory.
- [LinuxServer.io](https://www.linuxserver.io). Well-maintained images for hundreds of apps, all documented the same way.

## Communities

- [r/selfhosted](https://www.reddit.com/r/selfhosted/) for apps and "what should I use for X" questions.
- [r/homelab](https://www.reddit.com/r/homelab/) for hardware, networking and people showing off their setups.
- [r/HomeServer](https://www.reddit.com/r/HomeServer/), which is a bit friendlier to beginners than r/homelab.
- Most apps have a Discord or GitHub Discussions page. Search there before asking.

## YouTube

- [Techno Tim](https://www.youtube.com/@TechnoTim): clear home lab tutorials on Docker, Proxmox, networking and Kubernetes.
- [Jeff Geerling](https://www.youtube.com/@JeffGeerling): Raspberry Pis, hardware and actual benchmarks.
- [Christian Lempa](https://www.youtube.com/@christianlempa): home lab from more of a DevOps and security angle.
- [Wolfgang's Channel](https://www.youtube.com/@WolfgangsChannel): low-power and budget servers.
- [NetworkChuck](https://www.youtube.com/@NetworkChuck): very beginner-friendly intros to networking, Linux and Docker.

## App docs

- Pi-hole: https://docs.pi-hole.net
- Each app in [04 Explore](04-explore/) has its docs linked at the top of its README.

## Free stuff for students

- The [GitHub Student Developer Pack](https://education.github.com/pack) has free cloud credits and a free domain name, which is handy for a home lab.
- [Oracle Cloud's free tier](https://www.oracle.com/cloud/free/) includes an always-free ARM server that a lot of people use for small projects.

## What to do next

1. Move one app off your laptop onto something that stays on: an old laptop, a Raspberry Pi or a cheap used mini PC.
2. Install [Tailscale](https://tailscale.com) so you can reach it from your phone anywhere, without opening any ports.
3. Write a Dockerfile for one of your own projects, like a Discord bot or a course project.

[06 Learn more](06-learn-more.md) goes into all of this.
